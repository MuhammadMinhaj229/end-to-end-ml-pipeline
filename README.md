# End-to-End ML Pipeline

A machine learning pipeline for customer churn prediction, demonstrating model training, serving, and a business dashboard.

## Problem / Motivation

The objective of this project is to build an end-to-end machine learning pipeline that predicts customer churn. This project explores how to take a machine learning model from a training script into a deployed API service with a front-end interface for users to interact with the predictions.

## Approach

1. **Model Training:** Developed a Python script (`src/train.py`) that generates a synthetic dataset using `scikit-learn`, trains an XGBoost classifier, and logs metrics and artifacts to MLflow.
2. **API Serving:** Created a RESTful API using FastAPI (`src/api.py`) that exposes endpoints for single (`/predict`) and batch (`/predict/batch`) predictions using the trained model. Pydantic is used for request validation.
3. **User Interface:** Built a Streamlit application (`app/streamlit_app.py`) that allows users to interact with the model by submitting single prediction forms or uploading CSVs for batch predictions.
4. **Containerization:** Containerized the API and the Streamlit UI using Docker and `docker-compose` for reproducible deployment.

## Results

- **Model Accuracy:** 0.88 on the synthetic test set (see output of `python src/train.py`).
- **Test Coverage:** 49% coverage across the `src` directory (measured via `pytest --cov=src`).

## How to Run Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/MuhammadMinhaj229/end-to-end-ml-pipeline.git
   cd end-to-end-ml-pipeline
   ```

2. **Run with Docker Compose (Recommended):**
   ```bash
   docker-compose up --build
   ```
   This will start the FastAPI backend on `http://localhost:8000` and the Streamlit frontend on `http://localhost:8501`.

3. **Run Tests:**
   You can run the test suite locally with:
   ```bash
   pip install -r requirements.txt
   pytest tests/ -v
   ```

## Limitations & Future Work

- **Dataset:** The current model is trained on a synthetic dataset generated by `sklearn.datasets.make_classification`. Real-world performance would require training on actual customer data.
- **Monitoring & CI/CD:** There is currently no active CI/CD pipeline or production drift monitoring configured in the repository.
- **Model Storage:** The model artifact is stored locally in the `models/` directory instead of a remote model registry.
- **Testing:** Test coverage is currently limited mostly to the API endpoints and does not cover the training script. Expanding the test suite is necessary for a production-ready application.
